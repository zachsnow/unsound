# Development

* Use `bun run usc` to invoke the compiler.
* Use `bun run build` to build the compiler binary; *do not* use the compiled binary during development.
  **Always** run the compiler with `bun run usc` during development.
* Use `bun run test` to run tests
* Use `bun run clean` to clean build artifacts and compiled code.
* Use `bun run install` to install the language server / VS Code extension.
