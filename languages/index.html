Unsound is an experimental framework for building extensible programming languages, created to explore first class type checking, language extensions, and inspired by the tagless final approach to language implementation. Try it out or learn more about how it works.

Unsound provides several language extensions that build on each other.

Layers

Core

The base language - a simple expression-oriented language:

let x = 42 in x
let f = (a, b) => a in f(1, 2)
if true then "yes" else "no"
{ x: 1, y: 2 }.x

Meso

Adds infix and prefix operators with precedence:

1 + 2 * 3
x > 0 && x < 10
!done || count == 0

Thermo

Adds imperative features - blocks, semicolons, assignment:

let x = 1;
let y = 2;
{
  x = x + y;
  x * 2
}

Programmable Types

Exo adds type annotation syntax, along with typechecking semantics.

let x : Number = 42;
let f: (n: Number) => Number = (n) => n + 1;
f(x)

In the interest of not spending more time building space elevator, Exo is implemented in TS directly on Core.

The interesting thing about Exo is how types and typechecking are implemented. Specifically, each type annotation is an Exo expression -- a value -- that is itself evaluated before performing type checking.

In addition, when interpreting a binding's value

let x: T = value;

We first evaluate T using the default $interpret semantics to determine the type. Then we evaluate value using the $type semantics, and compare the results using op== on T to determine whether value is assignable to x.

For more on writing your own languages, see Authoring Languages and Extensions.
